# Setup

## 1. Clone project

git clone https://github.com/Luxaztk/Cross-Platform-Music-Player-App.git

## 2. Install dependencies

npm install

## 3. Run desktop

npm run desktop

## 4. Run mobile

npm run mobile

### Yêu cầu mobile
- Phiên bản Expo Go: Sử dụng SDK 55 (https://expo.dev/go)
- Phiên bản Development Build: Tải
