# Setup

## 1. Clone project

git clone https://github.com/Luxaztk/Cross-Platform-Music-Player-App.git

## 2. Install dependencies

npm install

## 3. Run desktop

npm run desktop

## 4. Run mobile

npm run mobile

### Preview trên điện thoại
#### Sử dụng phiên bản Expo Go
1. Tải Expo Go SDK 55 tại [đây](https://expo.dev/go) và cài đặt
2. Mở app Expo Go > "Scan QR Code"
3. Nếu trên terminal đang hiện dòng chữ `Using development build...` thì bấm `s` 
4. Scan mã QR hiển thị trên terminal

#### Sử dụng phiên bản Development Build:
1. Tải Development Build tại [đây](https://github.com/Luxaztk/Cross-Platform-Music-Player-App/releases/download/mobile-v.0.0.0/application-1ee841f8-dde3-4f8d-9057-02608c881720.apk) và cài đặt (app sẽ có tên là `mobile`)
2. Mở app `mobile` > "Scan QR Code"
3. Nếu trên terminal đang hiện dòng chữ `Using Expo Go...` thì bấm `d` 
4. Scan mã QR hiển thị trên terminal

# Tài liệu (documentation)
- Xem trong thư mục `docs/`
- Quy tắc đặt tên:
    - Nếu là tài liệu liên quan đến bài tập lớn -> Tên bắt đầu bằng `__BTL_`
    - Nếu là tài liệu liên quan đến dự án chung (desktop + mobile) -> Tên bắt đầu bằng `__PROJECT_`
    - Nếu là tài liệu về desktop -> Tên bắt đầu bằng `__DESKTOP_`
    - Nếu là tài liệu về mobile -> Tên bắt đầu bằng `__MOBILE_`
